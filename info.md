# Crestron DM NVX for Home Assistant

Local NVX video/audio routing, status, HDMI controls, OSD messages, CEC event
entities, Identify and optional preview snapshots.

Requires Home Assistant 2024.12 or newer and authenticated HTTPS access to
each device. Install as a HACS custom repository.
